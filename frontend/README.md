# Frontend

Interface React com TypeScript e Vite. Requer Node.js 22.12 ou superior na linha 22.

```powershell
npm install
npm run dev
```

O módulo de voluntários consome `http://localhost:8080/api/v1/volunteers`. Para apontar a interface para outra URL, defina `VITE_API_BASE_URL` antes de iniciar o Vite. Os demais módulos permanecem como áreas planejadas.
